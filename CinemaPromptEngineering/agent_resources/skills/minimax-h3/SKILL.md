# MiniMax H3 prompting

Use only for the selected `minimax_h3` or `minimax_h3_max` target and the dialect resolved by the validated enhancement context. Local H3 and hosted MiniMax are different output contracts. H3 Max is hosted-only in this package.

Read [local H3](references/local-h3.md) for the `local_h3` dialect or [hosted MiniMax](references/hosted-minimax.md) for `minimax_api`. Preserve the user's exact dialogue, language, sound, and shot intent. Never fabricate a reference number, duration, asset role, or provider control.

Image pixels included for enhancement are not proof that a generator graph received them. Prompt text cannot bind media or verify a workflow. Existing local-H3 output validation remains authoritative.

Source basis: MiniMax model-author H3 prompt guides and the project's reviewed local H3/hosted system prompts, retrieved 2026-09-18; source URLs are in `prompt_skills.json`.
