# LTX Ingredients

Use only with the exact LTX-2.3 or LTX-2.5 Ingredients match selected by the caller. The input is one already-composed reference sheet, not a set of independent images. Do not invent panels, assemble a sheet, or claim the prompt itself binds it.

Return exactly these two parts for the Ingredients prompt contract:

```text
Reference sheet: <describe only supplied panels and their confirmed roles> / Generated video: <requested visible action and cinematic treatment>
```

Keep the two parts in that order. Preserve the sheet's supplied identity, style, or composition roles as requested. If pixels are not included in the enhancement request, use only the caller's description of the sheet. Do not leak this two-part format into ordinary LTX T2V/I2V prompts.
