# FLUX and Krea image prompting

Use the exact canonical target and any selected image dialect. FLUX.1, FLUX.1 Kontext, FLUX.1 Krea, FLUX.2 Dev, FLUX.2 Klein, Krea 2 Large, and Krea 2 Turbo are distinct matches; never borrow an editing or reference capability from a neighboring variant.

Read [FLUX variants](references/flux-variants.md) or [Krea variants](references/krea-variants.md). Lead with the user's main subject or requested edit, then add only useful supplied style, scene, light, color, layout, and preservation details. Preserve exact text. Concision and detail are both valid depending on the brief.

Reference images follow the selected capability dialect and caller-confirmed roles. Style reference does not imply identity or scene locking. Prompt prose cannot attach an image or verify the generator workflow.

Source basis: project FLUX/Kontext/Krea guides and model-author documentation; exact sources are in `prompt_skills.json`.
