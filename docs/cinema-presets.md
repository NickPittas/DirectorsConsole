# Cinema Presets

[Back to the README](../README.md)

These tables describe Cinema's application preset defaults, not verified historical production equipment. Use them as starting points; manual selections and explicit edits take priority. The current dropdown and [canonical preset definitions](../CinemaPromptEngineering/cinema_rules/presets/) are authoritative; this guide is not an exhaustive catalog.

For the underlying preset documentation, see [Film Presets 1](../CinemaPromptEngineering/Documentation/Film%20Presets%201.md), [Film Presets 2](../CinemaPromptEngineering/Documentation/Film%20Presets%202.md), [Film Presets 3](../CinemaPromptEngineering/Documentation/Film%20Presets%203.md), and [Animation Styles](../CinemaPromptEngineering/Documentation/Animation%20Styles.md).

### Illustration

Concept Art, Editorial Illustration, Book Illustration, Western Comics, Graphic Novel, Watercolor, Digital Painting

Animation selections configure a medium, style domain, line treatment, color application, lighting model, surface detail, motion style, and virtual-camera behavior. Current selections override defaults.
